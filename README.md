# Time Management 

Time Management is a system I wrote to observer my own Behavior. I find it fascinating finding patterns in everything, including my own life.

To track myself I am using [ManicTime](https://www.manictime.com/) it records information about the Active Window throughout the day. It already provides many features to view how one uses the computer day to day.

It can be hard to have a clear view of how long you actually work in a day. With Time Management you can grouping Activities. Easy to read Graphics then tell you how you spent each day.  

Currently Development of the [App](./TimeViewer/) allows for daily analysis. To understand the larger picture [Analysis](./Analysis/) can bring clearity. My Goal is to eventually show these larger Statistics into the App.
